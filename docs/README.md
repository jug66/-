阅读顺序：先看需求说明书，再按需查阅调研证据。两份文档的范围或候选规则有差异时，以需求说明书的当前版本为准；新增产品默认值仍须与用户明确确认的要求区分。

后续维护以新增数据库迁移、回归测试及更新接口/运行文档为基本流程。P1/P2 功能仍属于后续范围。
