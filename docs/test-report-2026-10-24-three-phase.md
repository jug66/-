# 三阶段增强验证记录

日期：2026-10-24。范围：三阶段前端、导航和产品能力增强。

## 结果

- 后端 `mvn test`：24 个测试通过，1 个耗时压测入口按默认配置跳过，构建成功。
- 前端 `npm test`：13 个测试通过。
- 前端 `npm run build`：`vue-tsc -b && vite build` 通过。
- 真实 Chromium 深层回归：连续展开 85 层，缓存达到上限后自动聚焦到当前分支，显示 6 张卡片，360px 宽度无横向溢出，页面错误数为 0。
- 后端定向验证覆盖：祖先继续加载、最近回复、编辑窗口、版本冲突、编辑历史、通知去重与已读、搜索可见性、线程统计、管理员状态和举报处理。

## 新增验证内容

1. 祖先游标带目标留言签名，跨留言或篡改游标会返回 400。
2. 搜索游标绑定关键词，隐藏和删除留言不会出现在结果中。
3. 编辑要求作者身份、版本号和时间窗口；编辑历史只允许作者读取。
4. 回复通知按收件人和回复留言去重，标记已读只影响当前用户的通知。
5. 管理员入口和举报处理继续由后端 `ADMIN_USER_IDS` 权限控制。
6. 线程统计使用当前根留言关系计算后代数量和最近活动时间。
7. LRU 回归保护当前可见分支，避免深层展开到缓存上限时回收上级路径。

## 当前边界

- 没有接入 WebSocket/SSE 实时推送；最近回复和通知由页面主动加载。
- 图片仍使用单机本地目录，未接入对象存储、CDN 或病毒扫描。
- 管理员账号仍由环境变量配置，不提供自助角色管理。
- 未进行公网部署、断电恢复、跨浏览器矩阵和渗透测试。
