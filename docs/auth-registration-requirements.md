# 账号与注册管理需求

| 项目 | 内容 |
| --- | --- |
| 版本 | v1.0 |
| 日期 | 2026-10-21 |
| 状态 | 本轮开发基线 |
| 适用范围 | ECHO 留言板的注册、登录和账号恢复 |

## 1. 目标

降低普通用户注册时的密码门槛，同时保留服务端会话、CSRF、Argon2id 和请求限流等安全措施。账号恢复采用可选邮箱：没有邮箱的用户仍可注册和发言，填写邮箱的用户可以完成邮箱验证和密码找回。

## 2. 注册规则

### 2.1 登录名

- 去掉首尾空白后按小写归一化。
- 只允许 ASCII 小写字母、数字和下划线，长度 3～32 个字符。
- 归一化后的登录名唯一。
- 登录名不能使用保留名称：`admin`、`administrator`、`moderator`、`system`、`support` 等管理或系统名称。

### 2.2 显示名称

- 可选；为空时使用登录名。
- 去掉首尾空白后长度为 1～30 个 Unicode 码点。
- 允许重名，不参与权限判断。

### 2.3 密码

- 长度为 9～128 个 Unicode 码点。
- 允许空格、Unicode 和密码管理器粘贴。
- 不强制大小写、数字或特殊字符组合。
- 注册和修改密码时拒绝内置常见密码及明显的账号相关密码。
- 密码只保存 Argon2id 散列，不保存明文，不写入日志。
- 登录和注册错误不返回密码是否正确的详细原因。

### 2.4 邮箱

- 邮箱为可选字段，最大长度 320 个字符。
- 如果填写，按小写和首尾空白归一化后保存，必须通过验证链接确认。
- 同一个邮箱地址只能绑定一个账号。
- 未验证邮箱的账号仍可登录、阅读和发布留言；邮箱只影响恢复能力。

## 3. 登录与恢复

- 登录继续使用服务端 Session，登录成功轮换 Session ID。
- 登录接口同时按 IP 和归一化登录名限流；错误提示统一为“账号或密码不正确”。
- 新增“忘记密码”接口。无论账号或邮箱是否存在，都返回相同的成功提示，避免账号枚举。
- 找回链接使用一次性随机 token，数据库只保存 token 哈希，默认 30 分钟过期，使用后立即失效。
- 重置密码仍需满足 9～128 位和常见密码拦截规则。
- 邮件发送通过可替换的邮件服务完成；本地未配置 SMTP 时只记录脱敏后的开发提示，不把 token 放入 HTTP 响应。

## 4. 界面要求

- 注册表单显示“密码 9～128 个字符，可使用空格”。
- 密码输入支持显示/隐藏，并保留浏览器自动填充和粘贴能力。
- 注册表单增加可选邮箱字段，并说明邮箱用于找回密码。
- 登录表单提供“忘记密码”入口。
- 忘记密码提交后始终显示统一提示，不暴露账号是否存在。
- 网络失败时保留当前输入，不清空密码以外的注册内容。

## 5. 数据与接口变更

新增 Flyway 迁移，给 `board_user` 增加邮箱及验证时间，并新增一次性账号 token 表。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| POST | `/api/auth/register` | 注册，增加可选 `email` |
| POST | `/api/auth/login` | 登录，规则不变但增加账号维度限流 |
| POST | `/api/auth/forgot-password` | 请求密码找回，固定返回成功提示 |
| POST | `/api/auth/reset-password` | 使用一次性 token 设置新密码 |
| GET | `/api/auth/verify-email` | 验证邮箱 token |

## 6. 验收标准

1. 9 位密码可以注册，8 位密码被拒绝，129 位密码被拒绝。
2. 包含空格、中文或 emoji 的 9～128 位密码可以注册并正常登录。
3. `Password1!` 这类常见或明显弱密码被拒绝，并返回可理解的提示。
4. 注册时填写邮箱会保存为未验证状态；重复邮箱被拒绝。
5. 不填写邮箱仍可完成注册、登录和发布留言。
6. 连续错误登录会触发 IP 或账号维度限流，换账号不能绕过 IP 限制。
7. 不存在的账号和真实账号请求找回密码返回相同 HTTP 状态和提示。
8. 找回 token 只能使用一次，过期 token 和重复使用 token 均被拒绝。
9. 重置后的密码可以登录，旧密码不能登录。
10. 后端不返回密码、密码散列或未脱敏 token。

## 7. 明确不包含

本轮不实现 OAuth、GitHub 登录、Google 登录、Passkey、TOTP 二次验证、管理员审核和邀请制。这些功能保留到后续账号安全增强版本。
