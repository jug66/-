# 留言板可靠性改造 Implementation Plan

**Goal:** 按已批准的执行顺序补齐治理、资源预算、生产配置、深层浏览和内容维护。
**Architecture:** 有界接口和现有邻接表继续保留。治理和上传预算使用 PostgreSQL 事务锁，客户端模块维护 LRU 和请求代次。
**Tech Stack:** Java 21 / Spring Boot / MyBatis / PostgreSQL / Vue 3 / TypeScript。
**Spec:** ../specs/2026-10-23-board-hardening-design.md

## Progress at 2026-10-23

已完成：V4 治理、V5 用户上传额度、生产配置校验、分支 LRU、直接回复统计、文档和集成验证。剩余：管理员 UI、IP/磁盘全局配额、祖先继续加载、线程状态 UI、编辑修订、通知和搜索。
